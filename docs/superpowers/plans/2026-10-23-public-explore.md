# 公開 Explore 與行情連續性

使用者已要求依交接內容直接實作。沿用 Next.js、現有積木元件與 Supabase/PGlite；偏好 AssetMetra 的資訊層次，保留 STACK 視覺。版面細節為實作判斷，不是交接對話已批准的逐項規格。

## 已確認

- 未登入 `/market` 回 307；頁面與 `(app)` layout 都要求登入。
- 本機 PGlite 目前有 28 筆資產，market_daily、market_group_daily、market_sync_log、benchmark_prices 都是 0 筆。此次本機空白不是休市把舊行情刪掉，而是從未同步市場資料。
- 現有頁面依賴輪動計算完成，暖機不足會連可用行情一起隱藏。

## 實作

1. 市場專用匿名唯讀角色與 RLS；公開三個市場 GET，私人帳本保持登入。登入後才額外讀自己的持股。
2. `/market` 移至登入 layout 外，使用公開導覽；首頁 Explore 入口直接連市場。
3. 行情與輪動分離：最近有效行情日、輪動資料日獨立標示，休市不強制查今天；暖機或新版本回補仍顯示收盤行情、成交額與法人缺值狀態。
4. 以公開市場摘要、產業／族群積木牆、成分股明細分層；延用象限與既有工具。空資料、暖機、來源錯誤分開呈現，不造行情。
5. 同步時先取最新資料，再回補歷史，避免新安裝只看到很早的資料。

## 驗證

先測試重現匿名存取、週末查上週五、只有行情沒有輪動、舊版本回補與無行情；再改程式。匿名與使用者隔離以 PGlite 驗證；瀏覽器檢查公開頁、手機尺寸、私有頁轉址、成分股請求。最後執行 lint、型別、測試（限制 workers）與建置。

不部署、不提交、不改動既有私人帳本。正式 Supabase 需套用新增 migration。
