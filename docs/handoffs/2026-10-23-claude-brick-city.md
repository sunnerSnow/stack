核准概念圖：[A 立體積木城市](assets/explore-city-approved-a.png)。圖中數字僅供構圖參考，實作必須使用目前資料來源。幾何與操作以此圖為方向；配色以原站規範為準。

使用者目的：一眼從大盤看到各產業／族群的資金偏向，再點特定族群深入個股，保留積木組裝、拆解的動畫體驗。借用 AssetMetra 的「總覽 → 群組 → 個股」探索概念，建立 STACK 自己的積木表達。

## 必須呈現的視覺與資料語義

| 元件 | 表達內容 | 驗收重點 |
| --- | --- | --- |
| 中央低矮積木廣場 | 大盤指數、漲跌、成交額、資料日 | 真實行情，總覽第一眼可讀 |
| 可辨識凸點的產業底板 | 產業區域與分類關係 | 連接成城市，區名清楚 |
| 底板上的立體積木塔 | 族群 | 由實際積木層疊成，不是卡片或散點旁貼積木圖示 |
| 塔的占地 | 成交額的相對規模 | 大小有差異，圖例解釋尺度 |
| 塔的層數 | 法人淨買賣絕對幅度 | 相對分級、有上限，正負不靠高度區分 |
| 塔的主色與文字 | 法人買超／賣超／零／缺值 | 黃＝買超、海綠＝賣超，零與缺值可區分；文字與圖例同時說明 |
| 拆出的個股積木 | 所選族群的成分股 | 清楚維持來源關係，真實資料 |
| 詳細面板 | 成分股、漲跌、成交、法人資料 | 單位、日期、缺值明確 |

沿用 `web/src/app/globals.css` 與 `web/src/components/bricks.tsx` 的品牌語言：奶油白 `#F5F0E5`、海軍藍 `#173451`、黃 `#F5D548`、海綠 `#187F7C`，加上粗框、凸點、實體側面和有方向的陰影。金融紅／綠只用於金融數值。概念圖的珊瑚色不作品牌色。保持畫面乾淨、文字可讀，積木本身就是資料載體。

地理位置只表分類布局，沒有 RS 座標含義。第一屏用城市作主體；既有 RS 輪動工具可留在下方進階區域。不要把星系散點圖、光暈或軌道效果搬進城市。

## 互動要求

1. 開啟 `/market` 即可公開瀏覽最近有效行情，無須登入。
2. 初始可見中央大盤與各產業底板。概覽若只放每區前幾大族群，須顯示已顯示／總數，並有清楚的展開入口；所有族群都可找到。
3. 點底板聚焦該產業；點族群塔高亮，拆出其個股積木並開啟資料面板。能返回產業、返回全景、清除選取。
4. 支援桌面與手機的選取、縮放／平移或等效可用導覽；按鈕、搜尋與選單提供鍵盤操作。手機不能只有縮小到無法閱讀的桌面圖。
5. 初始入場、聚焦與拆解／合攏使用積木組裝動畫。提供動畫控制，遵循 `prefers-reduced-motion`。組裝動畫不可標示為歷史資金回放。
6. 詳細資料請求顯示載入、空資料、失敗重試，快速切換時不顯示上一族群的過期回應。登入與私人持股功能維持既有界線。

## 真實資料與現有程式入口

- 專案根目錄 `/Users/yuki/Project/stack`，應用程式在 `web/`。先讀 `web/AGENTS.md`，Next.js 相關修改依其要求查本機版本文件。
- 主頁 `web/src/app/market/page.tsx`，目前主元件 `market-galaxy.tsx`。新城市可拆出自己的元件，替換主畫面並同步更新閱讀說明、metadata；保留下方完整數據／輪動工具。
- 品牌積木元件：`web/src/components/bricks.tsx` 的 `HomeBrick`、`RowBrick`；可擴充適合堆疊的幾何，但須保持同一造型語言。
- `web/src/lib/services/market-overview.ts`：`MarketOverviewDto` 有市場摘要、有效日期、各來源日期、所有 sector／industry／theme 群組及 parentId、turnover、ret、flow。不能把重疊族群加總當作全市場。
- `web/src/lib/services/market.ts` 與公開 `/api/market/groups/[id]?date=...`：群組詳情包含真實成分股、成交、漲跌、法人及日期。請直接確認目前型別與回應形狀。
- 已備純函式 `web/src/lib/market/city-layout.ts` 及 `web/tests/city-layout.test.ts`，可直接使用或調整：`buildCityDistricts(groups, level, focusedSectorId?, selectedGroupId?)`；區域分類、概覽前六、聚焦全部、選取保留、占地與層數已實作。這是工具，不是視覺成品；若全展開過密，需解決排版。
- `web/src/lib/market/viewport.ts` 有平移縮放工具，選擇適合城市的操作即可。

資料規則：缺值保留 null，不能補成零。休市顯示最近有效交易日，輪動暖機不足不能隱藏已有收盤行情。法人部分缺值時不可把部分合計標成完整合計。法人淨買賣與動畫不代表真實逐筆資金路徑。城市位置、層數與占地的語義必須有圖例。不要硬編概念圖或本次交接中的行情數字。
