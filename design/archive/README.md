這個資料夾是品牌改名為 **STACK** 之前的設計稿，當時暫名「洋流」，視覺是霧白＋深海藍＋海流青。保留下來只是為了記錄設計的演進，**不是現行設計**。

- `index.html` 等 7 頁：第一版 App 內頁設計稿（總覽、持倉、資產詳情、市場、快速更新庫存、匯入中心、樣式指南）
- `landing-a.html`：首頁原型 A（深海洋流）
- `landing-b.html`：首頁原型 B（積木 Pop），之後發展成 STACK
- `video/`：A、B 兩個原型的錄影

現行的 STACK 視覺：首頁原型在 [`../landing-stack.html`](../landing-stack.html)，App 實作在 [`../../web/`](../../web/)。
