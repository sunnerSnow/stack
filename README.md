# STACK

**Build Your Financial World.** 把投資，一塊一塊拼起來。

STACK 是整合市場分析、個人資產管理與 AI 投資研究的模組化投資平台：

- **EXPLORE 探索市場**：產業資金流向、法人買賣超、個股強度、產業輪動
- **BUILD 組合資產**：多組合、多帳戶、台股美股、現金與股息；淨值、損益、XIRR、TWR 都可解釋、可追溯
- **DISCOVER 發掘觀點**：把持倉和產業、新聞、技術指標接起來，每個結論都標示資料時間、來源與不確定性
